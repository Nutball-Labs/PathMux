clops_gpsexport

Non-interactive GPS track exporter for dashcam trips

Synopsis

clops_gpsexport MID:TID [--gpx PATH] [--kml PATH] [--geojson PATH] [--force] [--verbose]

Description

clops_gpsexport exports the GPS track for a dashcam trip to one or more file formats without navigating the interactive GPS menu (camclops -G). It is suitable for scripting, batch export, and pipeline use.

If the trip's GPS track has not yet been extracted, clops_gpsexport runs ExifTool extraction automatically and stores the result in the manifest before writing any output files. Subsequent invocations for the same trip skip extraction and write directly from the cached track. Extraction runs at most once per invocation regardless of how many output formats are requested.

A trip is addressed by its MID:TID (e.g. CQ:73), where MID is the two-character manifest ID and TID is the two-character trip ID. Both are case-insensitive; ambiguous characters are normalised (O→0, I→1, L→1).

Options

--gpx PATH
Write a GPX 1.1 track file.
--kml PATH
Write a KML 2.2 track file with a gx:Track element containing per-point timestamps, speed, and heading.
--geojson PATH
Write a GeoJSON FeatureCollection (RFC 7946) with one LineString feature. Coordinates are in [longitude, latitude] order per the spec.

At least one format flag is required. Multiple flags may be combined in a single invocation; GPS extraction runs only once.

PATH Resolution

PATH omitted
Auto-name the output file in the current directory using the trip's start timestamp as the stem (e.g. 20260209_043838.gpx).
PATH ends with /
Auto-name in the specified directory.
PATH is an existing directory
Auto-name in that directory.
PATH is a full file path
Use that path exactly. Extension is appended if missing.

Other Options

--force
Overwrite existing output files without prompting. Without this flag, clops_gpsexport exits with an error if an output file already exists.
--verbose
Show ExifTool stderr during GPS extraction. Useful for diagnosing extraction failures or understanding minor tag warnings. Has no effect if extraction is skipped (track already in manifest).
-v, --version
Print the CamClops version string and exit.
-h, --help
Print a usage summary and exit.

Output

Progress messages (extraction dots, status lines) are written to stderr. Exported file paths are written to stdout on success, one path per line. This makes the output pipeable:

clops_gpsexport CQ:73 --gpx /tmp/ | xargs -I{} cp {} /media/usb/

GPS Extraction

If GPS has not been extracted for the trip, clops_gpsexport runs ExifTool on every Front camera segment and stores the resulting track (one point per second) in the trip manifest. The manifest MD5 is updated automatically so --validate does not flag the file as externally modified.

The ExifTool binary path is read from ~/.config/camclops/camclops.json. See the camclops help page, section GPS Extraction, for details on the format string and camera compatibility.

Output Formats

GPX 1.1

Produces a standard GPX track with one <trkpt> per GPS record. Each point includes latitude, longitude, an ISO 8601 timestamp, and speed in metres per second as a <extensions> element. Elevation is omitted for Pruveeo D90 footage (altitude values are unreliable on that model).

KML 2.2

Produces a KML document containing start and end placemarks and a gx:Track element with per-point timestamps, coordinates, speed, and heading in ExtendedData arrays. The track line style is solid red; start pin is green, end pin is red. Compatible with Google Earth and other KML viewers.

GeoJSON (RFC 7946)

Produces a FeatureCollection with one Feature containing a LineString geometry. Properties include creator, trip_id, date, start_time, duration, segment_count, and point_count.

Examples

Export GPX only, auto-named in current directory:
clops_gpsexport CQ:73 --gpx
Export KML to an explicit path:
clops_gpsexport CQ:73 --kml /mnt/maps/trip.kml
Export all three formats in one pass:
clops_gpsexport CQ:73 --gpx /tmp/ --kml /tmp/ --geojson /tmp/
Force overwrite of existing files:
clops_gpsexport CQ:73 --gpx /tmp/trip.gpx --force
Show ExifTool output during extraction:
clops_gpsexport CQ:73 --gpx /tmp/ --verbose

Files

~/.config/camclops/camclops.json
Application settings including exiftoolPath. GPS extraction arguments are stored in the camera profile embedded in the manifest.
~/.config/camclops/manifests.json
Manifest index used for MID:TID resolution.
<footage_path>/clops_manifest_<id>.json
Trip manifest. Updated in-place after GPS extraction.

Exit Status

0
All requested output files written successfully.
1
Failure: MID:TID not resolved, GPS extraction failed, output file exists without --force, or a write error occurred.
