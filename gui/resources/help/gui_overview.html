PathMux GUI Overview

pathmux-gui — Qt6 desktop interface for dashcam trip management

Main Window Layout

The main window is a horizontal split view:

  • Left panel (Manifest Panel): Lists all known footage sources (manifests). Each entry shows the footage path, number of trips, and date range.
  • Right panel (Trip Grid): Shows trip tiles for the selected manifest. Each tile displays the trip date, start time, duration, segment count, and a thumbnail from the trip.

Drag the center divider to resize the panels. Use Ctrl+Scroll over either panel to zoom the tile size.

Scanning Footage

To add a footage source:

  1. Use Manifests > Scan Source Directory (or Ctrl+O).
  2. Navigate to the top-level dashcam footage directory (the one containing Front/, Rear/, etc. subdirectories).
  3. Click OK. A progress dialog shows scan status.
  4. When complete, the manifest appears in the left panel and its trips appear in the right panel.

Viewing Trips

Click a manifest in the left panel to load its trips. Each trip is shown as a tile in the right panel with:

  • Date and start time
  • Duration and segment count
  • Distance (if GPS data has been extracted)
  • GPS status indicator
  • Thumbnail image from the trip

Double-click a trip tile to open the Trip Properties dialog, which shows detailed trip information and provides access to video build and GPS export functions.

Trip Properties Dialog

The Trip Properties dialog shows:

  • Trip metadata: date, start time, duration, segment count, distance
  • GPS information: status, lock time, start/end coordinates
  • Segment list: all video files in the trip; double-click a segment to open it in the system video player

From the Trip Properties dialog you can:

  • Build Video — open the video build dialog to assemble per-camera MP4 files or a 4K collage
  • Export GPS — export GPS tracks as GPX, KML, or GeoJSON (extracts GPS data if not yet done)

Video Build Dialog

The Video Build dialog lets you configure and run a video build for a trip:

  • Toggle which camera channels to include (Front, Rear, Left, Right)
  • Select collage resolution (4K / 1080p)
  • Configure audio source for the collage
  • Set the output directory

Build progress is shown in a separate dialog with per-stage status rows. Multiple stages can run concurrently (concat runs per-camera in parallel).

Settings Dialog

The Settings dialog covers:

  • Paths: ffmpeg binary, ExifTool binary, default export directory
  • Camera Profile: active profile ID; controls trip detection layout
  • Display: imperial/metric units toggle
  • Encoder: preset selection and individual encoder parameters (host-specific; saved to the host overlay file)

Setup Wizard

The Setup Wizard walks through the minimum configuration needed to get started:

  1. ffmpeg and ExifTool binary paths
  2. Default export directory for GPS tracks and video files
  3. Encoder preset (CPU / VAAPI / NVENC / QSV)

The wizard can be re-run at any time from Tools > Setup Wizard. It pre-populates all fields with the current saved settings, so you can update just the one field you need.

First-Run Behavior

On first launch (no config file found), the Setup Wizard runs automatically. Complete the wizard to configure your system, then use Manifests > Scan Source Directory to add your first footage source.

GPS Cold-Start Warning

Important: Dashcam GPS receivers typically require 30–120 seconds to acquire a satellite fix after power-on. No GPS data is recorded during this period. If you use GPS track data for mileage logs, tax records, or legal documentation, be aware that the first portion of every trip may be missing from the GPS track. The distance shown in PathMux is great-circle distance between first and last recorded fix — not total odometer distance.
