clops_ls

Non-interactive trip lister for CamClops manifests

Synopsis

clops_ls [--json | --format=fmt [--fields=f1,f2,...]] [MID | MID:TID]

Description

clops_ls lists dashcam trips from cached CamClops manifests. It is the scriptable, pipe-friendly alternative to camclops -t and camclops -T. All output goes to stdout; errors go to stderr.

Without arguments, clops_ls prints a one-line summary for every trip across all manifests, grouped under a manifest header line. A MID argument filters output to one manifest. A MID:TID argument prints a full detail block for a single trip.

Both MID and TID are case-insensitive. Ambiguous characters are normalised (O→0, I→1, L→1).

Options

--json
Emit JSON instead of text. With no filter, outputs an array of manifest objects each containing a trips array. With MID:TID, outputs a single trip object. Suitable for piping to jq.
--format=fmt
Structured output format. Valid values: json, csv, xml.
json
Equivalent to --json; --fields is ignored.
csv
One record per trip, comma-separated with a header row. Use --fields to select columns.
xml
One <trip> element per trip inside a <trips> root. Use --fields to select child elements.
--fields=f1,f2,...
Comma-separated list of fields to include in csv or xml output. Ignored for json. Available fields:
manifest_id, trip_id
Manifest and trip identifiers.
address, date, start_time, start_epoch
Human-readable address (if geocoded), calendar date, wall-clock start time, and Unix epoch of trip start.
duration, duration_seconds
Trip length as formatted string and raw seconds.
segment_count, note
Number of video segments; optional free-text note.
start_lat, start_lon, end_lat, end_lon
Start and end coordinates in decimal degrees (requires GPS extraction).
distance_km, distance_mi
Great-circle distance between start and end coordinates.
gps_lock_seconds
Seconds from segment start until first GPS fix. Requires GPS extraction; zero if not yet run.
gps_track_status
One of none, partial, or complete.
-v, --version
Print the CamClops version string and exit.
-h, --help
Print a usage summary and exit.

Default Output Format

MID TID Date        Start     Duration  Segs  Distance  GPS
----------------------------------------------------------------
[CY]  /z/srcdash/ex10
CY  7E  2026-02-25  04:44:24  18m 29s   7     22.7 km   pts
CY  0Y  2026-02-25  13:56:53  42m 6s    15    56.8 km   pts

Columns:

MID
Two-character manifest ID.
TID
Two-character trip ID within the manifest.
Date
Trip date in YYYY-MM-DD format.
Start
Trip start time in HH:MM:SS format (local time from filename timestamps).
Duration
Human-readable trip duration (e.g. 39m 52s).
Segs
Number of video segments in the trip.
Distance
Crow-flies haversine distance between the trip start and end GPS coordinates. Displayed in km or miles depending on the useImperial preference. Shows - if no GPS coordinate data is available for the trip.
GPS
GPS data availability indicator:
track
Full per-second GPS track has been extracted (via camclops -G or clops_gpsexport). Ready for GPX/KML/GeoJSON export.
pts
Start and end coordinates only, captured automatically during the initial -s scan. Sufficient for distance calculation; run clops_gpsexport to extract the full route.
-
No GPS data. Typically a cold-start stub segment where the GPS receiver never acquired a fix.

Detail Output (MID:TID)

Trip:       X1:87
Date:       2026-02-09
Start:      04:38:38
Duration:   39m 52s
Segments:   14
Seg dur:    180s
Manifest:   /z/srcdash/ex2/clops_manifest_X1.json
Source:     /z/srcdash/ex2
Start pos:  30.419000, -89.025191
End pos:    30.367684, -89.613496
Distance:   56.7 km
GPS:        complete  (lock: 0s)

Duration shows the computed ffprobe duration in parentheses if available: 39m 52s (ffprobe: 39m 51s). GPS shows the track status and GPS lock time in seconds if it has been scanned by clops_gpsinfo --scan-all-trips.

JSON Output

{
  "id": "87",
  "date": "2026-02-09",
  "start_time": "04:38:38",
  "duration": "39m 52s",
  "segment_count": 14,
  "segdur": 180,
  "distance_km": 56.71,
  "start_lat": 30.419,
  "start_lon": -89.025,
  "end_lat": 30.367,
  "end_lon": -89.613,
  "gps_status": "complete",
  "gps_lock_sec": 0,
  "duration_ffprobed": -1,
  "note": ""
}

distance_km is -1 if no GPS coordinates are available. duration_ffprobed is -1 if the ffprobe duration has not yet been computed. gps_lock_sec is -1 if --scan-all-trips has not been run for that trip.

Examples

List all trips across all manifests:
clops_ls
List trips for manifest X1 only:
clops_ls X1
Show detail for one trip:
clops_ls X1:87
JSON output for all manifests, extract trip IDs with jq:
clops_ls --json | jq '.[] | .trips[] | .id'
JSON output for one manifest:
clops_ls --json X1
Find all trips with full GPS tracks:
clops_ls --json | jq '.[] | .trips[] | select(.gps_status == "complete") | .id'

Files

~/.config/camclops/manifests.json
Manifest index listing all known manifests.
~/.config/camclops/camclops.json
Application settings (useImperial controls distance display units).

Exit Status

0
Success.
1
No manifests found, unknown MID, or unknown TID.
