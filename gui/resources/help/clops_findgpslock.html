clops_findgpslock

Report GPS lock acquisition time for dashcam footage segments

Synopsis

clops_findgpslock [--verbose] file.ts [file2.ts ...]

Description

clops_findgpslock scans one or more Pruveeo D90 dashcam .ts segments and reports when GPS lock was acquired relative to the start of each clip.

The Pruveeo D90 firmware does not write GPS records into the LIGO stream until a satellite fix is acquired. The lock offset (+Ns) is computed by comparing the UTC timestamp of the first valid GPS record against the local clip-start time encoded in the filename, using epoch arithmetic for accuracy across midnight crossings and DST boundaries.

For each file, clops_findgpslock prints a header line with the filename and the clip-start time derived from the filename, followed by the lock line showing the offset and the first valid GPS fix.

Options

-v, --version
Print version information and exit.
-h, --help
Print a usage summary and exit.
--verbose
Pass verbose flags to ExifTool and show its stderr output during the scan. Useful for diagnosing extraction failures.

Output

# 20260216_095422F.ts  2026-02-16 09:54:22
  lock +107s  20260216 15:56:09    30.415534   -89.027873

The header line shows the filename and the clip-start time (local) derived from the filename. The lock line shows:

lock +Ns
Seconds elapsed from clip start until the first valid GPS fix.
timestamp
GPS lock time in UTC (YYYYMMDD HH:MM:SS).
lat lon
Latitude and longitude at the moment of lock, in decimal degrees.

If no valid GPS record is found in the file, the message (no GPS lock found) is printed instead.

Notes

Filename timestamps are in local time; GPS timestamps are in UTC. The offset computation accounts for the timezone difference via mktime (local) and timegm (UTC).

A lock offset of +0s is theoretically possible on a warm-start trip where the receiver retained its last fix. In practice the D90 typically shows 20–120 seconds on a cold start.

This tool is diagnostic. Lock times are stored automatically in the trip manifest by clops_gpsinfo --scan-all-trips and surfaced in the interactive browser and clops_ls.

Exit Status

0
At least one file processed without error.
1
Bad arguments or file not found.
