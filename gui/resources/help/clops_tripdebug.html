clops_tripdebug

Trip detection debugger for CamClops

Synopsis

clops_tripdebug [-T | -f] path_to_dashcam_folder

Description

clops_tripdebug runs CamClops trip detection directly against a dashcam footage directory and displays the results without reading or writing any manifest. It is a diagnostic tool for verifying that footage is being grouped into trips as expected.

Without options, clops_tripdebug prints a summary table of detected trips. Use -T for a full segment listing or -f for an interactive drill-down.

Options

-T, --tree
Print the complete segment tree for every detected trip and exit. Each segment shows its timestamp and which cameras (Front/Rear/Left/Right) have footage files present.
-f, --full
Interactive mode. Displays the summary list, then prompts for a trip ID to inspect. Enter a numeric ID to see its segment tree. Enter R to redraw the summary, Q to quit.
-v, --version
Print the CamClops version string and exit.
-h, --help
Print a usage summary and exit.

Output — Summary (default)

  ID    Start Timestamp      Duration        Segments
  -----------------------------------------------------------------
  1     2026-02-09 04:38:38  1h 22m 14s      83
  2     2026-02-09 08:14:01  0h 34m 07s      35

2 trip(s) detected.

Output — Tree (-T or -f drill-down)

Trip #1  [2026-02-09  04:38:38]  duration=1h 22m 14s  segments=83
-----------------------------------------------------------------
  [  1]  20260209_043838  [F.L.]
         F: 20260209_043838F.ts
         L: 20260209_043838L.ts
  [  2]  20260209_043938  [FBLR]
  ...

Camera presence indicators: F = Front, B = Rear, L = Left, R = Right. A dot (.) means that camera has no file for that segment timestamp.
